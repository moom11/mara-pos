# مارا — نظام تسجيل خروج القلابات ومبيعات مواد الجبل

نظام لتسجيل خروج القلابات المحمّلة بمواد الجبل (دفان، سبيس، ...). يعمل من المتصفح على **الجوال والكمبيوتر**، وكل البيانات محفوظة في **قاعدة بيانات دائمة** (SQLite) على الخادم، فيرى الجميع نفس البيانات.

## آلية العمل
- كل خروج قلاب من الموقع = **رد واحد**، وسعر الرد يُدخل عند التسجيل.
- عند «تأكيد الخروج» تُحفظ العملية مع **التاريخ والوقت واسم الموظف** تلقائياً، ويصدر **سند خروج برقم متسلسل** قابل للطباعة (A5 بنموذج الشركة، أو طابعة إيصالات 80 ملم).
- الضغط على الزر أكثر من مرة **لا يكرر الحفظ**.
- يظهر **تنبيه** إذا سُجلت اللوحة نفسها خلال وقت قصير (المدة تُضبط من الإعدادات).
- اسم السائق وسعر الرد واسم العميل والمادة تُحفظ **داخل كل عملية**، فلا تتغير السجلات السابقة عند تعديل البيانات الأساسية.

## الصلاحيات
| الصلاحية | ما يمكنه |
|---|---|
| موظف بوابة | تسجيل الخروج، إضافة قلاب أو عميل جديد، طباعة سندات اليوم |
| مدير | كل شيء: الملخص، التقارير، التعديل والإلغاء (مع السبب)، سداد العملاء، الإعدادات، المستخدمين |

كل تعديل أو إلغاء يُحفظ في **سجل التغييرات** مع اسم المستخدم والوقت والسبب والقيم قبل وبعد.

## الشاشات
- **تسجيل خروج:** اللوحة (كتابة، أو اختيار قلاب محفوظ، أو قراءتها من صورة 📷)، السائق، العميل، المادة، السعر، طريقة الدفع (نقد / تحويل / آجل)، المدفوع، والمتبقي يُحسب تلقائياً.
- **الرئيسية:** ملخص اليوم.
- **العمليات:** بحث وتصفية وطباعة وتعديل وإلغاء.
- **العملاء:** الرصيد وكشف الحساب (الردود، المبيعات، المدفوعات، المتبقي) وتسجيل السداد. السداد يخصم من الرصيد ولا يُحسب مبيعات.
- **التقارير:** حسب الفترة واللوحة والعميل ونوع المادة: عدد الردود، المبيعات، التحصيل النقدي، التحويلات، الأرصدة المتبقية. مع طباعة وتصدير إلى **Excel** و**PDF**.
- **القلابات والسائقين، الأصول، الإعدادات** (بيانات الشركة والشعار، أنواع المواد، المستخدمين، النسخ الاحتياطي).

## التشغيل

### 1) على كمبيوتر في المكتب أو الموقع (الأسهل)
1. ثبّت [Node.js](https://nodejs.org) الإصدار 20 أو أحدث.
2. نزّل المشروع، ثم من داخل مجلده نفّذ:
   ```bash
   npm install
   ```
   ```bash
   npm start
   ```
3. افتح `http://localhost:3000` على نفس الكمبيوتر.
4. من **الجوال**: اتصل بنفس شبكة الواي فاي وافتح العنوان الذي يظهر عند التشغيل، مثل `http://192.168.1.20:3000`.
5. أول مرة يطلب البرنامج إنشاء **حساب المدير**. بعدها أضف حسابات موظفي البوابة من الإعدادات.

> يجب أن يبقى هذا الكمبيوتر يعمل أثناء العمل. قاعدة البيانات في الملف `data/mara.db`.

### 2) على خادم سحابي (للوصول من أي مكان)
يعمل على أي خادم يدعم Node.js مع **قرص دائم** (VPS، أو Railway/Render مع Volume/Disk):
- `PORT`: المنفذ (الافتراضي 3000).
- `DB_FILE`: مسار ملف قاعدة البيانات على القرص الدائم، مثل `/data/mara.db`.
- `TZ`: المنطقة الزمنية (الافتراضي `Asia/Riyadh`).

يُفضّل تشغيله خلف HTTPS عند استخدامه عبر الإنترنت.

## النسخ الاحتياطي
من **الإعدادات ← تنزيل نسخة احتياطية** يُنزَّل ملف قاعدة البيانات كاملاً. للاستعادة: أوقف البرنامج وضع الملف مكان `data/mara.db` ثم شغّله.

# مارا — نظام تسجيل خروج القلابات ومبيعات مواد الجبل

نظام لتسجيل خروج القلابات المحمّلة بمواد الجبل (دفان، سبيس، ...). يعمل من المتصفح على **الجوال والكمبيوتر**، وكل البيانات محفوظة في **قاعدة بيانات دائمة** (SQLite) على الخادم، فيرى الجميع نفس البيانات.

## آلية العمل
- كل خروج قلاب من الموقع = **رد واحد**، وسعر الرد يُدخل عند التسجيل.
- عند «تأكيد الخروج» تُحفظ العملية مع **التاريخ والوقت واسم الموظف** تلقائياً، ويصدر **سند خروج برقم متسلسل** قابل للطباعة (A5 بنموذج الشركة، أو طابعة إيصالات 80 ملم).
- الضغط على الزر أكثر من مرة **لا يكرر الحفظ**.
- يظهر **تنبيه** إذا سُجلت اللوحة نفسها خلال وقت قصير (المدة تُضبط من الإعدادات).
- اسم السائق وسعر الرد واسم العميل والمادة تُحفظ **داخل كل عملية**، فلا تتغير السجلات السابقة عند تعديل البيانات الأساسية.

## الصلاحيات
| الصلاحية | ما يمكنه |
|---|---|
| موظف بوابة | تسجيل الخروج، إضافة قلاب أو عميل جديد، طباعة سندات اليوم |
| مدير | كل شيء: الملخص، التقارير، التعديل والإلغاء (مع السبب)، سداد العملاء، الإعدادات، المستخدمين |

كل تعديل أو إلغاء يُحفظ في **سجل التغييرات** مع اسم المستخدم والوقت والسبب والقيم قبل وبعد.

## الشاشات
- **تسجيل خروج:** اللوحة (كتابة، أو اختيار قلاب محفوظ، أو قراءتها من صورة 📷)، السائق، العميل، المادة، السعر، طريقة الدفع (نقد / تحويل / آجل)، المدفوع، والمتبقي يُحسب تلقائياً.
- **الرئيسية:** ملخص اليوم.
- **العمليات:** بحث وتصفية وطباعة وتعديل وإلغاء.
- **العملاء:** الرصيد وكشف الحساب (الردود، المبيعات، المدفوعات، المتبقي) وتسجيل السداد. السداد يخصم من الرصيد ولا يُحسب مبيعات.
- **التقارير:** حسب الفترة واللوحة والعميل ونوع المادة: عدد الردود، المبيعات، التحصيل النقدي، التحويلات، الأرصدة المتبقية. مع طباعة وتصدير إلى **Excel** و**PDF**.
- **القلابات والسائقين، الأصول، الإعدادات** (بيانات الشركة والشعار، أنواع المواد، المستخدمين، النسخ الاحتياطي).

## التشغيل

### 1) على كمبيوتر في المكتب أو الموقع (الأسهل)
1. ثبّت [Node.js](https://nodejs.org) الإصدار 20 أو أحدث.
2. نزّل المشروع، ثم من داخل مجلده نفّذ:
   ```bash
   npm install
   ```
   ```bash
   npm start
   ```
3. افتح `http://localhost:3000` على نفس الكمبيوتر.
4. من **الجوال**: اتصل بنفس شبكة الواي فاي وافتح العنوان الذي يظهر عند التشغيل، مثل `http://192.168.1.20:3000`.
5. أول مرة يطلب البرنامج إنشاء **حساب المدير**. بعدها أضف حسابات موظفي البوابة من الإعدادات.

> يجب أن يبقى هذا الكمبيوتر يعمل أثناء العمل. قاعدة البيانات في الملف `data/mara.db`.

### 2) على خادم سحابي Railway (للوصول من أي مكان) — خطوة بخطوة
التكلفة: اشتراك Hobby بـ 5 دولار شهرياً ويشمل 5 دولار استخدام، وهذا يكفي هذا النظام عادة.

1. **إنشاء الحساب:** ادخل [railway.com](https://railway.com) واضغط **Login** ثم **Login with GitHub** بنفس حساب GitHub الذي فيه المشروع. اشترك في خطة **Hobby**.
2. **إنشاء المشروع:** اضغط **New Project** ← **Deploy from GitHub repo**. إذا لم يظهر المستودع اضغط **Configure GitHub App** واسمح لـ Railway بالوصول إلى `mara-pos`، ثم اختره.
3. **اختيار الفرع:** إذا كان الكود في فرع غير `main`: افتح الخدمة ← **Settings** ← **Source** ← **Branch** واختر الفرع الذي فيه الكود.
4. **إضافة قرص التخزين الدائم (مهم جداً):** على لوحة المشروع اضغط بالزر الأيمن (أو **+ Create**) ← **Volume**، واربطه بخدمة `mara-pos`، واكتب مسار التركيب **`/data`**.
   > بدون هذه الخطوة تضيع البيانات عند كل تحديث، ويظهر تحذير أحمر في شاشة الدخول.
5. **الرابط:** افتح الخدمة ← **Settings** ← **Networking** ← **Generate Domain**. سيظهر رابط مثل `mara-pos-production.up.railway.app`.
6. **التشغيل الأول:** افتح الرابط وأنشئ **حساب المدير**، ثم من **الإعدادات** أضف حسابات موظفي البوابة.
7. **على الجوال:** افتح الرابط ثم اختر **إضافة إلى الشاشة الرئيسية** (في آيفون من زر المشاركة، وفي أندرويد من قائمة المتصفح)، فيظهر البرنامج كتطبيق بأيقونة مارا.

**ملاحظات:**
- كل تحديث يُرفع إلى الفرع على GitHub ينشره Railway تلقائياً، والبيانات تبقى محفوظة في القرص.
- النظام يأخذ **نسخة احتياطية تلقائية يومياً** داخل القرص (آخر 30 يوماً). ونزّل نسخة من **الإعدادات** بين فترة وأخرى واحفظها خارج الخادم.
- الإعدادات الجاهزة موجودة في `Dockerfile` و`railway.json`، ولا حاجة لإضافة متغيرات. المتغيرات الاختيارية: `TZ` (الافتراضي `Asia/Riyadh`) و`DB_FILE` (مسار قاعدة البيانات).
- يمكن تشغيله على أي خادم آخر يدعم Docker بنفس الطريقة، مع ربط قرص دائم وضبط `DB_FILE`.

### 3) على خادم Oracle Cloud في جدة (البيانات داخل السعودية) — خطوة بخطوة
خادم مستقل للبرنامج بشبكة منفصلة، فلا يتأثر به أي خادم آخر في الحساب (مثل خادم الموارد البشرية).

**أ) إنشاء الخادم**
1. من لوحة Oracle Cloud: **☰ ← Compute ← Instances ← Create instance**.
2. **Name:** `mara-pos-server`.
3. **Image:** اضغط **Change image** واختر **Ubuntu** ثم **Canonical Ubuntu 24.04**.
4. **Shape:** اضغط **Change shape** واختر **Ampere ← VM.Standard.A1.Flex** بـ 1 OCPU و 6GB ذاكرة (عليها علامة Always Free).
   إذا ظهرت رسالة نفاد السعة (Out of capacity) جرّب **VM.Standard.E2.1.Micro** (مجاني أيضاً)، أو أي حجم صغير مدفوع.
5. **Networking:** اختر **Create new virtual cloud network** و **Create new public subnet**، وتأكد أن **Automatically assign public IPv4 address** مفعّل.
6. **Add SSH keys:** اختر **Generate a key pair for me** واضغط **Download private key**. احفظ الملف في مكان آمن ولا ترسله لأحد.
7. اضغط **Create** وانتظر حتى تصبح الحالة **Running**، وانسخ **Public IP address**.

**ب) فتح منفذي الويب 80 و 443**
1. في صفحة الخادم، اضغط رابط **Subnet** ثم تبويب **Security** ثم **Default Security List**.
2. **Add Ingress Rules:** Source CIDR = `0.0.0.0/0`، IP Protocol = TCP، Destination Port Range = `80,443` ثم **Add Ingress Rules**.

**ج) تشغيل سكربت التثبيت**
1. افتح **Cloud Shell** من أعلى لوحة Oracle (أيقونة `>_`).
2. من قائمة Cloud Shell (⚙️ أو ☰) اختر **Upload** وارفع ملف المفتاح الذي نزّلته.
3. اكتب (مع تغيير اسم الملف والعنوان):
   ```bash
   chmod 600 ssh-key-*.key
   ```
   ```bash
   ssh -i ssh-key-*.key ubuntu@<Public IP>
   ```
   أجب بـ `yes` عند السؤال.
4. على الخادم، انسخ هذا الأمر كما هو:
   ```bash
   curl -fsSL https://raw.githubusercontent.com/moom11/mara-pos/refs/heads/claude/nice-mccarthy-vv8okk/deploy/oracle/install.sh | sudo bash
   ```
   يستغرق 5 إلى 10 دقائق، وفي النهاية يظهر **رابط البرنامج** مثل `https://152-70-1-2.sslip.io`.
5. افتح الرابط، وأنشئ **حساب المدير**، ثم أضف موظفي البوابة من الإعدادات.

**بعد التثبيت**
- **نطاق خاص (اختياري):** وجّه سجل `A` لنطاق مثل `trucks.example.com` إلى عنوان الخادم، ثم أعد تشغيل أمر التثبيت مع إضافة `-s -- --domain trucks.example.com` بعد `sudo bash`.
- **التحديث:** على الخادم `sudo mara-update`.
- **النسخ الاحتياطي:** يومياً تلقائياً في `/var/lib/mara/backups` (آخر 30 يوماً)، وأيضاً من **الإعدادات ← تنزيل نسخة احتياطية**. ويُنصح بتفعيل **Backup Policy** لقرص الخادم من صفحته في Oracle.
- **سجل البرنامج عند أي مشكلة:** `journalctl -u mara -n 100`.

## النسخ الاحتياطي
من **الإعدادات ← تنزيل نسخة احتياطية** يُنزَّل ملف قاعدة البيانات كاملاً. للاستعادة: أوقف البرنامج وضع الملف مكان `data/mara.db` ثم شغّله.

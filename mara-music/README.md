# Mara Music — مشغّل موسيقى مارا

مشغّل موسيقى يعمل على جهاز ويندوز داخل المطعم، ويُتحكَّم فيه بالكامل من الجوال.

الفكرة الأساسية: **جهاز الويندوز هو مصدر الحقيقة الوحيد** — هو الذي يخزّن الأغاني ويشغّلها.
الجوال مجرد ريموت كنترول، فإغلاق المتصفح أو الخروج من التطبيق لا يوقف الموسيقى.

## لماذا هذا التصميم

| الموقف | ماذا يحدث |
|---|---|
| انقطع الإنترنت | الموسيقى تستمر — كل الملفات على هارد الجهاز والتحكم عبر الواي فاي المحلي |
| أغلقت التطبيق في الجوال | الموسيقى تستمر — الجوال ريموت فقط |
| الموظف أغلق نافذة البرنامج | النافذة تختفي فقط، والتشغيل يستمر في الخلفية (أيقونة في شريط المهام) |
| أعيد تشغيل الكمبيوتر | البرنامج يفتح تلقائيًا ويستأنف نفس الأغنية من نفس الثانية |
| ملف صوتي تالف | يُتخطّى تلقائيًا وتكمل الموسيقى |
| وقت الصلاة | إيقاف أو خفض تلقائي، ثم استئناف بعد انتهاء الوقت المحدّد |

> **ملاحظة تقنية مهمة:** البرنامج **لا** يعمل كخدمة ويندوز (Windows Service)، لأن الخدمات
> تعمل في Session 0 ولا مخرج صوت لها. يعمل بدلًا من ذلك في جلسة المستخدم مع تشغيل تلقائي
> عند تسجيل الدخول — راجع [دليل التركيب](docs/SETUP-WINDOWS.md) لتفعيل الدخول التلقائي.

## المميزات

**التحكم من الجوال (صفحة عربية تُضاف لشاشة الآيفون الرئيسية):**
- تشغيل/إيقاف، التالي/السابق، التقديم والتأخير، مستوى الصوت
- قائمة "التالي": أضف أغنية لتشتغل بعد الحالية، أعد الترتيب، احذف، فرّغ القائمة
- المكتبة: بحث عربي ذكي (يتجاهل التشكيل والهمزات والتاء المربوطة)، فرز، تشغيل مباشر
- قوائم تشغيل: إنشاء، ترتيب، حذف، تشغيل فوري
- رفع أغانٍ MP3 من الجوال مباشرة إلى مكتبة الجهاز
- بثّ مباشر: أضف روابط محطات تملك حق تشغيلها، تُشغَّل كأي قائمة وبلا مساحة تخزين،
  ومع انقطاع الشبكة يعود المشغّل تلقائيًا لمكتبتك المحلية
- كل الأجهزة المتصلة ترى نفس الحالة لحظيًا (WebSocket)

**مود مارا ديجي (للمدير فقط):**
- **مزج تلقائي**: ينتقل قبل نهاية الأغنية بثوانٍ قابلة للضبط، فلا صمت ولا مقدمات طويلة
- **نيكس ديجي**: انتقال ممزوج بضغطة واحدة بدل القطع المفاجئ
- **كنس ترددي** على الأغنية الخارجة و**ذيل صدى** عند الانتقال
- **فلتر حيّ** من الجوال: غائر ↔ طبيعي ↔ مشدود
- **دروب**: شدّ تدريجي ثم انفراج مفاجئ
- ضاغط ديناميكي في نهاية المسار يحمي السماعات من قمم المؤثرات
- الفلتر والصدى لا يُحفظان: إعادة التشغيل تبدأ دائمًا بصوت طبيعي
- المؤثرات تُطبَّق على المكتبة المحلية فقط — البث المباشر يمرّ على مسار منفصل

**تلقائيًا:**
- إيقاف أو خفض الصوت في أوقات الصلاة (حساب فلكي محلي، بدون إنترنت — طريقة أم القرى افتراضيًا)
- جدولة زمنية: قائمة هادئة صباحًا، أنشط وقت الذروة، خفض الصوت آخر الليل
- مزج سلس بين الأغاني (crossfade) بمدة قابلة للضبط
- فحص مجلد الموسيقى تلقائيًا عند إضافة أو حذف ملفات

**الصلاحيات:**
- **مدير** (أنت): كل شيء
- **موظف**: تشغيل/إيقاف، التالي، ومستوى صوت بسقف محدّد — لا تعديل للقوائم أو المكتبة أو الإعدادات
- شاشة جهاز المطعم مبسّطة: الأغنية الحالية، التالي، وقت الصلاة القادم، ورمز QR للاتصال

## البنية

```
src/main/       العملية الرئيسية (Electron): الخادم، المكتبة، محرّك الحالة، الجدولة
  index.js      الإقلاع، النافذة، شريط المهام، التشغيل التلقائي
  server.js     واجهة HTTP + WebSocket + بثّ الملفات الصوتية (يدعم Range)
  player.js     محرّك الحالة — مصدر الحقيقة الوحيد للتشغيل
  library.js    فحص مجلد الموسيقى وقراءة بيانات الأغاني والأغلفة
  playlists.js  قوائم التشغيل
  scheduler.js  أوقات الصلاة + القواعد الزمنية
  prayer.js     حساب أوقات الصلاة محليًا
  auth.js       الأرقام السرية والرموز والصلاحيات
  store.js      تخزين JSON بكتابة ذرية (آمن عند انقطاع الكهرباء)
src/renderer/   نافذة جهاز المطعم: محرّك الصوت + الشاشة المبسّطة
src/web/        واجهة التحكم من الجوال (PWA عربية)
tools/          أدوات مساعدة (أيقونات، اختبارات، نقل، تنظيف، اختصارات)
```

البيانات (المكتبة، القوائم، الإعدادات، الحالة) تُحفظ في:
`C:\Users\<اسم المستخدم>\AppData\Roaming\Mara Music\data`

## التشغيل السريع (للمطوّر)

```bash
cd mara-music
npm install
npm run test-audio -- ./test-audio   # ملفات MP3 صامتة للتجربة (اختياري)
npm start
```

للاختبار بدون واجهة رسومية (يشغّل الخادم الحقيقي مع مشغّل صوت وهمي):

```bash
npm test
```

لبناء ملف التثبيت لويندوز:

```bash
npm run dist        # ينتج dist/MaraMusic-Setup-1.0.0.exe
```

## التركيب في المطعم

راجع **[docs/SETUP-WINDOWS.md](docs/SETUP-WINDOWS.md)** — دليل خطوة بخطوة:
التثبيت، الدخول التلقائي، جدار الحماية، حجز IP ثابت، إضافة الأغاني، وربط الآيفون.

لنقل البرنامج والبيانات إلى جهاز المطعم، وللنسخ الاحتياطي الدوري:
**[docs/DEPLOY-TO-MARA.md](docs/DEPLOY-TO-MARA.md)** — أو انقر `نسخة-احتياطية.bat` و`استعادة-نسخة.bat` مباشرة.

للتحكم من خارج المطعم عبر الإنترنت: **[docs/REMOTE-ACCESS.md](docs/REMOTE-ACCESS.md)**.

نموذج الأمان وما يجب فعله قبل الفتح للإنترنت: **[docs/SECURITY.md](docs/SECURITY.md)**.

## أدوات مساعدة لجهاز ويندوز

ملفات تُشغَّل بنقرتين من مجلد المشروع، أو من سطح المكتب بعد تشغيل
`اختصارات-سطح-المكتب.bat` مرة واحدة:

| الملف | ماذا يفعل |
|---|---|
| `تشغيل-مارا.bat` | يشغّل البرنامج بلا Node ولا أوامر |
| `تنظيف-الجهاز.bat` | يحرّر مساحة بحذف الملفات المؤقتة وذاكرات التخزين المؤقت |
| `ترتيب-الوثائق.bat` | يرتّب ملفات التنزيلات في مجلدات حسب نوعها |
| `نسخة-احتياطية.bat` | ينسخ الأغاني والقوائم والإعدادات إلى فلاشة |
| `استعادة-نسخة.bat` | يستعيدها على جهاز آخر |
| `اختصارات-سطح-المكتب.bat` | ينشئ اختصارات الأدوات على سطح المكتب |

أدوات التنظيف والترتيب والنقل **تعرض خطتها أولًا ولا تنفّذ إلا بعد تأكيد كتابي**،
ولا تمس المستندات وسطح المكتب والصور والتنزيلات والبرامج المثبّتة.

## واجهة الـ API (مختصر)

كل المسارات تحتاج `Authorization: Bearer <token>` من `POST /api/auth/login`.

| المسار | الوصف |
|---|---|
| `POST /api/auth/login` | دخول بالرمز، يعيد token ودور المستخدم |
| `GET /api/state` | حالة التشغيل الكاملة |
| `POST /api/player/:action` | play, pause, toggle, next, previous, seek, volume, mute, shuffle, repeat, source, play-now, play-next, enqueue, queue-move, queue-remove, queue-clear, resume-now, dj, dj-next, dj-drop |
| `GET /api/library` | بحث وفرز المكتبة |
| `GET /api/stream/:id` | بثّ الملف الصوتي (يدعم Range) |
| `GET/POST/PATCH/DELETE /api/playlists…` | إدارة القوائم |
| `POST /api/upload` | رفع ملفات صوتية (مدير) |
| `GET/POST/DELETE /api/streams…` | محطات البث المباشر (الإضافة والحذف للمدير) |
| `GET/PATCH /api/settings` | الإعدادات (مدير) |
| `GET /api/prayer` | أوقات الصلاة اليوم وحالة الإيقاف التلقائي |
| `WS /ws?t=<token>` | بثّ لحظي للحالة لكل الأجهزة |
